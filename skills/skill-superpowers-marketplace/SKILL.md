# Superpowers Marketplace

Curated Claude Code plugins for skills, workflows, and productivity tools.

## Installation

This skill was added via `/plugin marketplace add obra/superpowers-marketplace`.

## Available Plugins

### Superpowers (Core)

**Description:** Core skills library with TDD, debugging, collaboration patterns, and proven techniques
**Install:** `/plugin install superpowers@superpowers-marketplace`

### Elements of Style

**Description:** Writing guidance based on William Strunk Jr.'s The Elements of Style
**Install:** `/plugin install elements-of-style@superpowers-marketplace`

### Developing for Claude Code

**Description:** Resources for developing plugins and skills
**Install:** `/plugin install superpowers-developing-for-claude-code@superpowers-marketplace`
