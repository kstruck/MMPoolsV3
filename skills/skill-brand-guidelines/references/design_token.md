# Official Design Tokens

## Color Palette

### Primary Colors
| Name       | Hex       | Usage                                      |
|------------|-----------|--------------------------------------------|
| **Dark** | `#141413` | Primary text, Dark backgrounds, Borders    |
| **Light** | `#faf9f5` | Page backgrounds, Text on dark backgrounds |
| **Mid** | `#b0aea5` | Secondary text, subtle borders             |
| **Subtle** | `#e8e6dc` | Alternating row backgrounds, cards         |

### Accent Colors
*Use these for buttons, highlights, and graphics. Cycle through them to maintain visual interest.*

| Name       | Hex       |
|------------|-----------|
| **Orange** | `#d97757` |
| **Blue** | `#6a9bcc` |
| **Green** | `#788c5d` |

## Typography

### Headings
* **Family:** Poppins
* **Fallback:** Arial, Sans-serif
* **Usage:** All text 24pt or larger.

### Body Copy
* **Family:** Lora
* **Fallback:** Georgia, Serif
* **Usage:** Standard paragraphs and UI text under 24pt.

## Application Rules
1.  **Contrast:** Always test contrast. Prefer `#141413` text on `#faf9f5` background.
2.  **Shapes:** Non-text UI elements (like dividers or abstract shapes) should use the **Accent Colors**.
