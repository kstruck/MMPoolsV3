## 4. P1 replay after #290 merges — full runbook

Why this exists: P1 is stacked on `fix/payment-truth-p4-backfill`. When you
squash-merge #290, its N commits collapse into one new commit on main, so a
plain `git rebase origin/main` would try to re-apply P4's work on top of
itself. `--onto` transplants ONLY P1's five commits.

1. Open PowerShell in `D:\march-melee-pools` (the main checkout, not a
   worktree).
2. Run:

   ```bash
   git fetch origin
   ```

   You should see the fetch complete without errors (new `origin/main` after
   the #290 merge).
3. Run:

   ```bash
   git checkout claude/payment-truth-p1-setpaidstatus
   ```

   You should see `Switched to branch 'claude/payment-truth-p1-setpaidstatus'`
   (or "set up to track" if it's the first checkout). If git complains about
   local changes, stop and tell the session — do not force anything.
4. Run (this is the replay; `edae9af` is the LAST P4 commit — the tip of
   `fix/payment-truth-p4-backfill` and the parent of P1's first commit
   `bf7da54`):

   ```bash
   git rebase --onto origin/main edae9af claude/payment-truth-p1-setpaidstatus
   ```

   `edae9af` = tip of `fix/payment-truth-p4-backfill` as P1 was built on it.
   You should see `Successfully rebased and updated refs/heads/claude/payment-truth-p1-setpaidstatus`.
   **If you see conflicts instead: run `git rebase --abort` and hand it back to
   a session** — no P1 file overlaps #290's files, so a conflict means
   something unexpected happened.
5. Verify the branch now carries exactly five commits of its own:

   ```bash
   git log --oneline origin/main..claude/payment-truth-p1-setpaidstatus
   ```

   You should see exactly 5 commits: `feat(payments): setPaidStatus carries
   the detail fields…` plus four `fix(payments): … (codex r1/r2/r3/r4)`
   commits. If you see P4 commits (`fix(ops)`/`fix(migrations)`) in the list,
   the replay went wrong — stop, `git rebase --abort` won't help now, hand it
   to a session (the pre-replay tip is safe in `git reflog`).
6. Push the replayed branch:

   ```bash
   git push --force-with-lease origin claude/payment-truth-p1-setpaidstatus
   ```

   You should see `forced update`. `--force-with-lease`, never bare `--force`.
